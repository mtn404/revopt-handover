Drop the Utilidex logo file here as `utilidex-logo.png` (or `.svg`).

The Sidebar component (`components/Sidebar.tsx`) references `/utilidex-logo.png`.
If you save an SVG instead, edit the `src` prop in Sidebar.tsx to `/utilidex-logo.svg`.

Recommended size: 128 x 28 px (h-7 in Tailwind = 28px); the logo will be scaled
to fit while preserving aspect ratio.
